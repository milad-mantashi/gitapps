# GitApps — راهنمای ساده

نسخهٔ برنامه: **0.2.0** — نسخهٔ بسته: **0.2.0-1**

GitApps برنامه‌ای ترمینالی است که نسخهٔ نصب‌شدهٔ برنامه‌ها را با آخرین انتشار
رسمی GitHub مقایسه می‌کند و در صورت وجود آپدیت، لینک دانلود می‌دهد.
برنامه‌های متن‌باز و سورس‌بسته، هر دو قابل بررسی هستند.

## چه کارهایی انجام می‌دهد؟

- ثبت مخزن با `gitapps add OWNER/REPO`
- نمایش فهرست با `gitapps list`
- بررسی همه با `gitapps check`
- بررسی یک مخزن با `gitapps check OWNER/REPO`
- نمایش نسخهٔ خود ابزار با `gitapps --version`

نسخهٔ نصب‌شده هر بار دوباره بررسی می‌شود؛ لازم نیست آن را دستی وارد کنید.
LocalSend و Happ در فهرست اولیه هستند؛ وجودشان در فهرست به معنی نصب‌بودن نیست.

## نصب آسان با DEB مستقل

**وضعیت فعلی:** بستهٔ مستقل در محیط توسعه ساخته و استخراج و اجرا شده است؛
هنوز فایل DEB به بخش Releases این مخزن پیوست نشده است.
فایل محلی ساخته‌شده مخصوص amd64 و Ubuntu 26.04 است؛ سازگاری با توزیع‌های
قدیمی‌تر تأیید نشده است. ساخت محلی به معنی تست نصب واقعی با root نیست.

پس از دریافت بستهٔ سازگار با سیستم خود، از پوشهٔ دانلود اجرا کنید:

```bash
sudo apt install ./gitapps_0.2.0-1_amd64.deb
gitapps --version
```

این نوع بسته پایتون را در خود دارد و کاربر لازم نیست Python یا pip نصب کند.
بااین‌حال به کتابخانه‌های پایهٔ سیستم مانند glibc وابسته است؛ «مستقل» به معنی
اجرا روی هر لینوکس یا هر معماری نیست. DEB معمولی با پسوند `all` نوع دیگری است
که به Python سیستم نیاز دارد؛ این دو را اشتباه نگیرید.

## نصب از کد منبع

این روش به Python 3.10 یا جدیدتر و Git نیاز دارد:

```bash
git clone https://github.com/milad-mantashi/gitapps.git
cd gitapps
python3 install.py
```

بعد از نصب دیگر نیازی به نوشتن python3 نیست:

```bash
gitapps add domcyrus/rustnet
gitapps list
gitapps check
```

اگر دستور پیدا نشد، مسیر زیر را به تنظیمات شل اضافه کنید و ترمینال جدید باز کنید:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

پوشهٔ سورس را جابه‌جا یا حذف نکنید؛ نصب از سورس به آن اشاره می‌کند.
اگر قبلاً از سورس نصب کرده‌اید، `command -v gitapps` را بررسی کنید؛ ممکن است
دستور قدیمی در `~/.local/bin` جلوتر از `/usr/bin/gitapps` باشد. بستهٔ DEB عمداً
فایل‌های پوشهٔ شخصی شما را تغییر نمی‌دهد.

## معنی خروجی

| پیام | معنی |
|---|---|
| Update available | نسخهٔ جدیدتری منتشر شده؛ لینک را برای دانلود باز کنید |
| Up to date | نسخهٔ شما با آخرین انتشار برابر است |
| Unknown | نسخهٔ نصب‌شده قابل تشخیص نیست؛ نمی‌توان وجود آپدیت را تأیید کرد |
| Cannot compare | قالب نسخه پشتیبانی نمی‌شود؛ مقایسه حدسی انجام نمی‌شود |

## محدودیت‌های واقعی

- دستور `scan` و کشف خودکار همهٔ برنامه‌های سیستم **هنوز پیاده نشده است**.
- دانلود، نصب و ارتقای خودکار برنامه‌ها **هنوز وجود ندارد**.
- اعلان فعلی در ترمینال و هنگام اجرای `check` است؛ سرویس پس‌زمینه ندارد.
- ابزار جایگزین APT نیست؛ فهرست به‌روزرسانی APT را هنوز بررسی نمی‌کند.
- نام مخزن باید با دستور یا بستهٔ نصب‌شده برابر باشد، یا نگاشت اختصاصی داشته باشد.
  Happ دارای نگاشت `happ-desktop → happ` است.
- پشتیبانی عمومی AppImage، Flatpak، Snap و Docker هنوز وجود ندارد.
- تشخیص نام برنامه، اثبات منبع نصب آن نیست؛ فقط برنامه‌های مورد اعتماد را ثبت کنید.
- اینترنت و دسترسی به GitHub لازم است و محدودیت درخواست API ممکن است رخ دهد.
- خروجی برنامه فعلاً انگلیسی است.

اطلاعات شخصی فهرست در `~/.config/gitapps/repositories.json` یا مسیر تعیین‌شده با
`XDG_CONFIG_HOME` نگهداری می‌شود؛ این فایل در مخزن عمومی منتشر نمی‌شود.

## ساخت بسته برای توسعه‌دهنده

دستورها و جزئیات فنی در [راهنمای انگلیسی](README.md) هستند.
گردش‌کار `Standalone DEB` برای ساخت و تست بسته روی Ubuntu 22.04 تنظیم شده؛
موفقیت اجرا باید در Actions بررسی شود. خروجی آن artifact است، نه Release خودکار.

## نسخه‌گذاری و حذف

تغییرات در [CHANGELOG.md](CHANGELOG.md) ثبت می‌شوند. نسخهٔ برنامه از یک محل
در کد خوانده می‌شود. شمارهٔ انتهایی `-1` نسخهٔ بسته‌بندی DEB است.

حذف بسته با `sudo apt remove gitapps` انجام می‌شود؛ تنظیمات کاربر حفظ می‌شوند.
